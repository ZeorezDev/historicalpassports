# Passport cover coverage

Every country has a local 64×64 texture. Authenticity is tracked separately from file coverage.
Imported reviewed covers: 165/195. Original provisional substitutes: 30/195.

Research: after an initial HTTP 429 interruption, the ordinary-passport gallery supplied 166 country candidates and remaining countries were investigated separately. Every imported cover was visually reviewed, matched to its country, checked for a reusable individual file license and Commons warning categories. Sources include both photos/scans and vector depictions, not a guarantee of the latest edition.

Disputed licenses, proposed designs, AI-generated depictions and data-page images were excluded; see assets/rejected_sources.json. Wikipedia-only images without a verified Commons license were not imported. The remaining substitutes mean a suitable reusable cover was not verified in this research, not that no such image can exist.
